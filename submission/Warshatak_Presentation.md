# Warshatak — Presentation Outline
**Slide 1:** Warshatak / ورشتك — AI-assisted vehicle symptom intake; Mazen Almalki.
**Slide 2:** Problem — drivers struggle to communicate car noises and symptoms clearly.
**Slide 3:** Solution — bilingual conversational intake with editable dictation and attachments.
**Slide 4:** User journey — choose vehicle → describe → optionally attach → review → save locally.
**Slide 5:** Architecture — browser JS → Express API → context and retrieval → configurable AI providers.
**Slide 6:** Saudi localization — terminology, Arabic/English UI, guided questions.
**Slide 7:** Evidence — 40 symptom cards, 30 conditional patterns, 15 excerpts, 4 exact known recordings; no validated fault-diagnosis accuracy.
**Slide 8:** Privacy and safety — local browser history, server-side keys, tentative suggestions only.
**Slide 9:** Testing and limitations — scripted checks, independent audio evaluation pending, provider quotas.
**Slide 10:** Future roadmap — technician review, independently labeled audio, deployment validation.
